# Design System Notes

The site is a static editorial travel journal using:

- `Instrument Serif` for editorial display typography.
- `Inter` for interface labels, forms, and controls.
- Warm paper backgrounds, navy/ink text, muted metadata, soft borders, and restrained shadows.

## Editorial Studio tokens

Studio adds centralized supporting tokens in `styles.css`:

- `--studio-cream: #F5F1E8`
- `--studio-powder: #C7D8E6`
- `--studio-lavender: #D8CEE4`
- `--studio-sage: #C9D2C0`
- `--studio-charcoal: #242321`
- `--studio-warm-white: #FBF9F4`
- `--studio-soft-gray: #DCD9D2`

These tokens supplement the existing cover and archive palette without replacing it.
